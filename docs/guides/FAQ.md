# FAQ

**Is network upload on by default?** No. Contribution is OFF by default.

**Can BotScope estimate global bot traffic?** No. Local shares only; Internet-wide estimation is intentionally refused.

**What does DEMO mean?** Synthetic/example data. Never publish demo outputs as observational results.

**Why so many UNKNOWN labels?** Preferring UNKNOWN over forced certainty is a design goal.

**Is confidence a probability?** No — it is a heuristic score.
