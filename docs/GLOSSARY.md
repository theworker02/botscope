# Glossary

| Term | Meaning |
|------|---------|
| OBSERVED | Directly measured field/count from a sensor/source |
| CLASSIFIED | Label assigned by classifier with evidence |
| INFERRED | Enrichment or derived interpretation |
| ESTIMATED | Statistical estimate with explicit caveats |
| UNKNOWN | Valid outcome when evidence is insufficient |
| DEMO | Synthetic/example data — not real measurements |
| Bot Card | Inspectable identity card derived from signatures |
| .bscope | Local analysis session directory |
