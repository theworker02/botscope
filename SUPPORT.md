# Support

- **Docs:** start with [README.md](README.md), [docs/guides/QUICKSTART.md](docs/guides/QUICKSTART.md), and [FEATURES.md](FEATURES.md)
- **Bugs / features:** GitHub Issues (use the templates under `.github/ISSUE_TEMPLATE/`)
- **Security:** [SECURITY.md](SECURITY.md)
- **Diagnostics:** run `botscope doctor` or `botscope doctor --bundle support.zip` and attach only sanitized output

BotScope is an alpha research/engineering tool. Please label DEMO analyses clearly and do not treat local shares as Internet-wide statistics.
